## homelab

Running a 3-node k3s cluster managed entirely through GitOps. Everything is declarative, versioned, and automated.

- **Orchestration:** k3s
- **GitOps:** FluxCD
- **Config:** Kustomize + SOPS (age encryption)
- **Ingress:** Traefik + Cloudflare Tunnel
- **TLS:** cert-manager + Let's Encrypt (DNS-01 via Cloudflare)
- **Monitoring:** Prometheus + Grafana
- **Apps:** Linkding, Audiobookshelf, Homepage

The entire cluster state lives in a [Git repository](https://github.com/pvtnelson/k3sHomelab). Every change goes through a pull request.
